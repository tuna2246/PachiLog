# PachiLog

パチンコ店のイベント結果、並び、末尾、全台系などをスマホで記録し、あとから履歴と傾向を確認できる静的Webアプリです。

## GitHub Pagesで公開する方法

1. このフォルダーの中身をGitHubリポジトリへアップロードします。
2. GitHubのリポジトリで `Settings` → `Pages` を開きます。
3. `Build and deployment` の `Source` で `GitHub Actions` を選びます。
4. 数分後に表示される公開URLをスマホで開きます。

## データ保存について

記録はブラウザの端末内保存領域に保存されます。サーバーやGitHubには送信されません。そのため、別のスマホとの自動同期はありません。アプリ内の「設定」から定期的にバックアップを書き出してください。

既存データを消さずに、新しいバックアップの結果を追加・更新できます。全台系は「機種名・台数」、並びは「機種名・開始台番・終了台番」を保存でき、詳細画面とイベント別の傾向画面に表示されます。

## スマホへインストールする方法

- iPhone：Safariで公開URLを開き、共有ボタンから「ホーム画面に追加」を選びます。
- Android：Chromeで公開URLを開き、メニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

追加されたPachiLogアイコンから起動すると、URL欄のないアプリ表示になります。

## 主な機能

- 店舗とイベントの事前登録・管理
- 登録済みの店舗・イベントを選んで、日付と総差枚を記録
- 登録済みの結果を詳細画面から編集
- 全台系、ハーフ系、並び、末尾、メイン機種、角・角2などの傾向登録
- 強かった末尾、並び台数、機種、メモの登録
- 店舗別フィルターとキーワード検索
- 店舗・イベントで絞り込める、傾向タイプ・末尾別の自動集計
- 店舗・イベント・結果をまとめたJSON形式のバックアップ書き出し・読み込み（読み込み時は既存データを残して追加・更新）
- ホーム画面への追加、URL欄のないアプリ表示
- 基本画面のオフライン表示

外部ライブラリやビルド作業は不要です。`index.html` だけでも動作します。
